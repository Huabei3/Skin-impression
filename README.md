# Skin Impression - SCUT-FBP5500 Branch

## 项目概述
使用SCUT-FBP5500预训练模型在toMax肤色喜好数据集上进行推理测试。

## 数据集
- **SCUT-FBP5500**: 5500张人脸图像，颜值评分1-5分
- **toMax**: 肤色喜好数据集，每组33张同一人脸的不同肤色变体，评分0-1

## 模型架构
- **ResNet-18**: 18层残差网络
- **输入**: 224×224 RGB图像
- **输出**: 单个回归分数

## 实验结果

### 整体指标
- **总图像数**: 693张（21组，每组33张）
- **平均Spearman相关系数**: -0.0672
- **总体Pearson相关系数**: -0.0508
- **预测范围**: [3.248, 3.440]（区分度很低）
- **真实值范围**: [0.000, 1.000]

### 组内排序分析
详见 

**关键发现**：
- 高亮度组（h）：大部分呈负相关（-0.75到-0.19）
- 低亮度组（l）：大部分呈正相关（0.25到0.58）
- 中等亮度组（m）：接近零相关

### 问题分析
1. **模型输出范围极窄**：只有0.192的跨度，区分度很差
2. **任务不匹配**：SCUT-FBP5500训练于多维度颜值特征（五官、脸型等），而toMax只有肤色变化
3. **亮度偏见**：模型对不同亮度的肤色有不同的偏好倾向
